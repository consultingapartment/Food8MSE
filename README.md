# mse-financials

МХБ-ийн ([open.mse.mn](https://open.mse.mn)) хүнсний салбарын 8 компанийн санхүүгийн тайланг татаж, **нэг Excel файлд** нэгтгэнэ: компани бүр өөрийн нэрээр sheet-тэй, sheet дотор тайлан бүр нэг багана (толгойд тайлангийн огноо). Бүх sheet ижил загвар, ижил мөртэй. Файл `reports/FOOD mse.xlsx` — ажиллах бүрт шинэ файл үүсгэхгүй, нэг файлыг шинэчилнэ.

Компаниуд: APU, TUM, TCK, SUU, MFC, GAZR, MMX, MGLA

## Суулгах

```bash
pip install -r requirements.txt
```

Python 3.10+ шаардлагатай.

## Ажиллуулах

```bash
python -m mse_financials                       # бүх 8 компани, татаж нэгтгэнэ
python -m mse_financials --tickers APU SUU     # зөвхөн сонгосон
python -m mse_financials --no-pdf              # PDF татахгүй (зөвхөн Excel)
python -m mse_financials --skip-download --reports-dir ./миний_тайлан   # татахгүй, гар дээрх файлуудыг задлана
python -m mse_financials -v                    # дэлгэрэнгүй лог
```

| Сонголт | Тайлбар |
|---|---|
| `--tickers` | Тикерүүд. Анхдагч: 8 компани бүгд |
| `--reports-dir` | Татсан файлын хавтас. Анхдагч: `mse_reports` |
| `--out` | Гаралтын Excel. Анхдагч: `reports/FOOD mse.xlsx` |
| `--date` | «Өнөөдөр»-ийн огноо (`YYYY-MM-DD`), дутуу тайлангийн сануулгад. Анхдагч: өнөөдөр (Улаанбаатарын цаг) |
| `--if-due` | Зөвхөн цуглуулах өдөр ажиллана |
| `--show-schedule` | Хуваарийг харуулаад дуусна |
| `--skip-download` | Сүлжээ ашиглахгүй, хавтас доторх `.xls/.xlsx`-г л задлана |
| `--no-pdf` | PDF файл татахгүй |
| `--rebuild` | Байгаа Excel-ийг үл хэрэгсэж бүх тайланг шинээр нэгтгэнэ |
| `--check` | Юу ч татахгүй, Excel-д бичихгүй. Сайтад Excel-ийн сүүлийн баганаас **шинэ** ямар тайлан гарсныг л жагсаана (зөвхөн PDF-тэй бол тэмдэглэнэ). Алдаатай тикер байвал exit code 1 |
| `--notify` | Үр дүнг (нэмэгдсэн тайлан, алдаа, WARNING) Telegram-д илгээнэ. `--check`-тэй хамт бол шалгалтын үр дүнг илгээнэ |
| `--strict-ssl` | SSL гэрчилгээний гинж дутуу үед баталгаажуулалтгүй дахин оролдохгүй |

```bash
python -m mse_financials --check               # шинэ тайлан гарсан эсэхийг л харах
python -m mse_financials --check --notify      # үр дүнг Telegram-д илгээх
```

### Telegram мэдэгдэл

1. Telegram дээр `@BotFather`-аар бот үүсгэж token авна; ботодоо нэг мессеж бичээд chat id-аа авна.
2. Орчны хувьсагч тохируулна: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`. GitHub дээр: **Settings → Secrets and variables → Actions → New repository secret** (workflow эдгээрийг аль хэдийн уншдаг).
3. Тохируулаагүй бол `--notify` юу ч илгээхгүй, алдаа ч гаргахгүй. Token нь логт хэзээ ч бичигдэхгүй.

### SSL

Зарим МХБ-ийн сайт (`*.mse.mn`) гэрчилгээний гинжээ дутуу өгдөг. Зөвхөн `SSLError` гарсан үед, **зөвхөн `mse.mn` домэйн дээр** баталгаажуулалтгүй дахин оролдож, логт WARNING бичнэ. Бусад домэйн, `mse.mn`-ээс гадагш redirect-д хэзээ ч хэрэглэхгүй. Бүр хориглохыг хүсвэл `--strict-ssl`.

## Гаралт

```
reports/
  FOOD mse.xlsx                   нэг файл, компани бүр өөрийн нэрээр sheet (АПУ ХК, Сүү ХК, …)
mse_reports/<TICKER>/            татсан эх файлууд + manifest.json (GitHub руу орохгүй)
```

- **Толгой (мөр 4–9):** **Тайлангийн огноо** (`yyyy-mm-dd`), Үе (`2025 Q4`), Хамрах хугацаа (сар), МХБ-д ирүүлсэн огноо, Эх файл, Засвар/тэмдэглэл. Багана огноогоор эрэмбэлэгдэнэ. Excel тайлан олдоогүй компанийн sheet-д тэр тухай тэмдэглэл байна.
- **Мөр:** бүх компанид нийтлэг стандарт загвар — Баланс (эргэлтийн/эргэлтийн бус хөрөнгө, богино/урт хугацаат өр, эздийн өмч), Орлого ба ашиг алдагдал. Мөрийг нэрээр (хэвийн болгосон) таньдаг тул загвар нь компани, оноор ялгаатай байсан ч нэг мөрөнд таарна. Ямар ч компанид утга байхгүй мөр харагдахгүй (бүх sheet ижил мөртэй).
- **Нэгж:** бүгдийг **мянган төгрөг** болгож хөрвүүлнэ. Тайланд нэгж бичигдээгүй/буруу бол 1000 дахин зөрүүг автоматаар засч «Засвар/тэмдэглэл» мөрөнд тэмдэглэнэ. Баланс, орлогын тайланг **тус тусад нь** шалгана (нэг файл дотор нэгж нь ялгаатай байх тохиолдол бий — жишээ нь SUU 2024 Q4): баланс нь нийт хөрөнгийг компанийн медиантай, ОДТ нь орлого ÷ нийт хөрөнгийг харьцуулна.
- **Харьцааны шинжилгээ:** sheet бүрийн доод хэсэгт Excel **томьёо**гоор (шинэ тайлан орохад өөрөө тооцогдоно): ашигт ажиллагаа (маржин, ROA, ROE), DuPont, хөрвөх чадвар, өрийн даац, эргэлт (DIO/DSO/DPO/CCC), өсөлт (YoY). Орлогын мөрийг жилийн түвшинд хөрвүүлж (× 12 ÷ хамрах сар), дундаж үлдэгдлийг өмнөх оны Q4-тэй авна. Дүрмийг `mse_financials/ratios.py`-д тодорхойлсон.
- **Хяналт:** "Балансын зөрүү" мөр = Нийт хөрөнгө − (Өр + Эздийн өмч); 0 байх ёстой.
- Орлого/ашиг алдагдлын тайлант үеийн дүн нь оны эхнээс хуримтлагдсан (YTD) дүн.
- Дахин ажиллуулахад `mse_reports/` дахь татсан файлыг дахин татахгүй (`manifest.json`).

### Шинэчлэх дараалал

`reports/FOOD mse.xlsx` байгаа бол код юуг ч шинээр бүтээхгүй, компани бүрийг дарааллаар шалгана:

1. Компанийн sheet-ийн **сүүлийн баганын** тайлангийн огноог уншина.
2. Сайтаас зөвхөн түүнээс **хойших** үеийн тайланг татаж задална (хуучныг дахин татахгүй).
3. Шинэ тайлан байвал sheet-ийн баруун талд багана болгон нэмнэ, байхгүй бол `сүүлийн тайлан 2025 Q4 нэгтгэгдсэн — шинэ тайлан алга` гэж логлоод дараагийн компани руу шилжинэ.
4. Ямар ч компанид шинэ тайлан олдоогүй бол файлыг огт өөрчлөхгүй (GitHub-д commit гарахгүй).

Файл байхгүй, эвдэрсэн эсвэл `--rebuild` өгсөн бол бүх тайланг шинээр нэгтгэнэ. Зөвхөн сүүлийн баганаас **хойших** үеийг нэмдэг тул sheet дундах орхигдсон үеийг нөхөхийг хүсвэл `--rebuild` ашиглана. `--tickers`-ээр хэсэгчлэн ажиллуулсан ч бусад компанийн sheet устахгүй.

> `reports/FOOD mse.xlsx` нь анхнаасаа төслийн хавтсанд байсан Excel тайлангуудаар (APU, TUM, TCK, SUU, MFC, GAZR, MMX) бэлдсэн. Дараагийн автомат ажиллуулалт сайтаас татаж файлыг шинэчилнэ.

## Шинжилгээ (`mse_analysis`)

`reports/FOOD mse.xlsx` + `inputs/` → `reports/FOOD analysis.xlsx`. Юуг ямар үзүүлэлтээр, ямар томьёогоор хийхийг [`docs/ANALYSIS.md`](docs/ANALYSIS.md)-ээс үзнэ.

```bash
python -m mse_analysis                                   # бүх 8 компани, бүх хавтас
python -m mse_analysis --tickers APU SUU --no-technical  # сонгосон компани, техникгүй
python -m mse_analysis --import-trades food_8_trade_history.txt   # МХБ-ээс хуулсан арилжааны түүхийг inputs/prices руу нэмээд шинжилнэ
python -m mse_analysis --date 2026-10-17 --out /tmp/a.xlsx
python -m mse_analysis --fetch-prices                    # open.mse.mn/securities/{id}/tab/tradeinfo-оос хаалтын ханшийн түүх татаж market.csv, prices/-д нэгтгээд шинжилнэ
```

`--fetch-prices` (`mse_analysis/live.py`) нь сайтын Next.js server action-ыг дуудна (cookie шаардахгүй). Талбарын нэрийг бодит хариугаар батлаагүй тул анх удаа `inputs/_raw/`-д хариуг хадгална; ханш олдохгүй бол файлыг өөрчлөхгүй, алдаагаар дуусна. `prices.yml` нь ажлын өдөр 17:30 (Улаанбаатар) үүнийг өөрөө ажиллуулна.

**Гаралтын хавтаснууд:** Дүгнэлт · Оноо · Харьцаа · Харьцааны түүх · DuPont · Түүхэн хандлага · Задаргаа · Эрсдэл (Altman, Piotroski, хүүгийн мэдрэмж, эвцэлдэх орлого, арилжааны хөрвөх чадвар) · Үнэлгээ · Graham ба ногдол · Үнэлгээ 2.0 (нэгдсэн оноо, BCG, корреляци) · Эзэмшил · ЦА прогноз · Техник · ТА <тикер>.

**`inputs/` хавтас (гараар шинэчилнэ):**

| Файл | Агуулга |
|---|---|
| `market.csv` | `ticker,price,price_date,shares,dps,dps_year` — ханш хоосон бол арилжааны түүхийн сүүлийн хаалт |
| `ownership.csv` | `ticker,snapshot,big_holders,big_share,small_holders,small_share` — ҮЦТХТ-ийн судалгаа; мөр нэмж түүх хадгална |
| `prices/<ТИКЕР>.csv` | `date,open,high,low,close,qty,value` — `--import-trades`-аар шинэчлэгдэнэ |
| `assumptions.json` | хадгаламжийн хүү, шаардах өгөөж, оноо/босгын тохиргоо (`mse_analysis/config.py` дахь `Assumptions`) |

Ханш, ногдол, эзэмшлийн мэдээлэл хуучирсан бол (`Дүгнэлт` хавтасны "Өгөгдлийн анхааруулга") үнэлгээний хэсэг хуучин ханшаар тооцогдоно.

**GitHub:** `collect.yml` тайлан татсаны дараа шинжилгээг бас шинэчилнэ. `analyze.yml` нь `inputs/` эсвэл `FOOD mse.xlsx` өөрчлөгдөхөд (мөн **Run workflow** товчоор) зөвхөн шинжилгээг дахин тооцно. `inputs/trade_history.txt` нэрээр МХБ-ээс хуулсан арилжааны түүхийг оруулбал өөрөө `prices/` руу нэмнэ.

## Хуваарь: хуулийн хугацаа + 14 хоног

Тайлан өдөр бүр гардаггүй тул код зөвхөн **тайлан ирэх ёстой хуулийн хугацаанаас 14 хоногийн дараа** ажиллана. Хугацаа нь МХБ-ийн [Мэдээлэл ил тод байлгах дүрэм](https://mse.mn/uploads/images/laws/Disclosure%20and%20Transparency%20Rules%20(unofficial%20translation).pdf)-ээс:

| Тайлан | Хуулийн хугацаа | Цуглуулах өдөр | Заавал эсэх |
|---|---|---|---|
| Жилийн санхүүгийн тайлан (IFRS), 3.2 | 2-р сарын 10 | **2-р сарын 24** | заавал |
| 1-р улирал | (дүрэмд заагаагүй, 4-р сарын 30 гэж тооцсон) | 5-р сарын 14 | заавал биш |
| Хагас жилийн тайлан, 3.2 | 7-р сарын 20 | **8-р сарын 3** | заавал |
| 3-р улирал | (дүрэмд заагаагүй, 10-р сарын 30 гэж тооцсон) | 11-р сарын 13 | заавал биш |

Улирлын (Q1, Q3) тайланг дүрэм тусад нь заадаггүй ч SUU, MFC, GAZR, MGLA зэрэг компани ирүүлдэг тул оруулсан. Хэрэггүй бол `mse_financials/schedule.py` дахь `DEADLINES`-аас болон `.github/workflows/collect.yml` дахь cron-оос хасна. (`tests/test_schedule.py` хоёр газрын огноо таарч байгааг шалгана.)

```bash
python -m mse_financials --show-schedule     # хуваарь, дараагийн цуглуулах өдөр
python -m mse_financials --if-due            # зөвхөн өнөөдөр цуглуулах өдөр бол ажиллана (өөрийн cron/Task Scheduler-д)
python -m mse_financials                     # хэзээ ч гараар ажиллуулж болно
```

Хуулийн хугацаанд ирүүлээгүй (хоцорсон) компани байвал ажиллах үеийн логт `WARNING` гарна. Дараагийн цуглуулалт тэр тайланг автоматаар авна. Яаралтай бол гараар ажиллуулна.

## GitHub дээр автоматаар

`.github/workflows/collect.yml` нь дээрх 4 өдөр Улаанбаатарын 10:00 цагт кодыг ажиллуулж, `reports/` хавтсыг repo руу commit хийнэ (мөн Actions хуудсан дээрх **Run workflow** товчоор гараар ажиллуулна). Тохируулах:

1. Repo-г GitHub руу оруулна.
2. **Settings → Actions → General → Workflow permissions** хэсэгт **Read and write permissions** сонгоно.
3. **Actions** таб → **collect-reports** → **Run workflow** гэж нэг удаа туршина.

GitHub нь 60 хоног идэвхгүй **public** repo-ийн хуваарьт ажлыг унтраадаг. Тайлан жилд 4 л удаа орох тул workflow-д сар бүр `.keepalive` файлыг шинэчилдэг жижиг ажил (`keepalive`) орсон. Private repo бол шаардлагагүй.

Хэрэв GitHub-ийн сервер open.mse.mn рүү хандаж чадахгүй бол Actions алдаатай дуусна — тэр үед өөрийн компьютер дээр `python -m mse_financials` ажиллуулаад `reports/`-ийг commit хийнэ.

## Яаж ажилладаг вэ

1. `/securities` хуудаснаас тикер → `companyCode` олно. Олдохгүй бол `config.KNOWN_IDS`-ийг ашиглана.
2. `/securities/{code}/tab/financials` хуудсын "Санхүүгийн тайлан" хүснэгтээс файлын холбоос бүрийг олно. Үеийг файлын нэр, файл доторх огноогоос биш **хүснэгтийн мөрөөс** (Он, Улирал) авдаг (зөрвөл логт WARNING) тул `..._finance_report_xls_<hash>.xlsx` шиг нэртэй файлууд ч зөв таарна. Аудитын дүгнэлтийг алгасна.
3. Файлууд `issuers.mse.mn/uploads/finance_reports/` дээр байрладаг. Нэр дэх зай, `//`, `../../` зэргийг зөв боловсруулна. Файлын төрлийг агуулгаар нь тодорхойлно (зарим `.xls` холбоос үнэндээ PDF).
4. Excel (эсвэл текст PDF) тайлангаас Баланс (`СБТ/СБД/БС/Баланс…`) ба Орлого, ашиг алдагдлын (`ОДТ/ОТ/IS…`) sheet-ийг олж, мөр бүрээс тайлант үеийн (сүүлийн) тоог авч стандарт загварт байрлуулна. Аудитлагдсан тайланг ашиглахгүй.

## Хязгаарлалт

- **Excel ба PDF:** Нэг үеийн Excel (`.xls/.xlsx`) байвал **зөвхөн Excel-ийг** татаж ашиглана (PDF-ийг татахгүй). Зөвхөн PDF байвал дараах дарааллаар уншина:
  1. **Текст давхаргатай PDF** (жишээ нь TCK) — `mse_financials/pdf.py` мөрийн дугаараар задална (`pdfplumber`).
  2. **Скан PDF** — `tesseract` OCR (`ocr.py`). Баланс/ОДТ-ийн нийлбэрийн бүх шалгалт өнгөрвөл л авна.
  3. tesseract шалгалтад унавал, `ANTHROPIC_API_KEY` secret байгаа үед харааны загвараар (`vision.py`) уншина — энд ч мөн нийлбэрийн шалгалт заавал өнгөрнө. Түлхүүр байхгүй бол тайланг алгасаж WARNING гаргана (буруу тоо хэзээ ч нэгтгэхгүй).
  Excel ".xls" холбоос нь үнэндээ PDF байвал (зарим тайлан ийм) тэр үеийн жинхэнэ PDF-ийг мөн татна. PDF-ээс авсан үед Excel хувилбар гарвал түүнийг илүүд үзнэ. Жилийн тайлангийн PDF нь аудитлагдаагүй тоо байж болно.
- Жилийн тайлангийн Excel нь аудитаас өмнөх тоо байж болно.
- Загварт таарахгүй мөр (компанийн өвөрмөц мөр) орохгүй; `-v` үед логт гарна.
- Сайтын HTML бүтэц өөрчлөгдвөл холбоос олдохгүй. Тэр үед хуудас `mse_reports/_debug/<TICKER>.html` болж хадгалагдана.

## Харьцуулсан зураг ба Telegram

`python -m mse_analysis --charts` — `reports/charts/valuation.png` (оноо, P/E, P/B, ногдол ашгийн өгөөж, Graham, бодит үнэ цэнийн хөнгөлөлт) ба `ratios.png` (ROE, цэвэр ашгийн маржин, Current ratio, Өр/Өмч, орлого ба ашгийн өсөлт) үүсгэнэ — бүх компанийг харьцуулсан.

Excel Telegram-д явахгүй: `reports/FOOD mse.xlsx` (татсан тайлан), `reports/FOOD analysis.xlsx` (сүүлийн шинжилгээ) хоёр ажиллах бүрд репод commit хийгдэж хадгалагдана (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` secrets шаардана; байхгүй бол алгасна).
`prices.yml` Даваа–Баасан 15:00 (УБ)-д (арилжаа 10:00–13:00; зөвхөн тухайн өдрийн хаалт — өөр өдрийн хуудас, баярын өдөр алгасна): ханш татах → шинжилгээ → зураг → Telegram → commit.
